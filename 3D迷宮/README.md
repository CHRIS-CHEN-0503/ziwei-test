# 🌀 3D移動迷宮

目前版本：**v1.10.0**（版本號顯示在遊戲標題畫面下方與後台設定，改版時同步更新 `index.html` 裡的 `GAME_VERSION`）

給國小學生玩的 3D 變形迷宮遊戲，支援平板 / 手機觸控與電腦鍵盤。

## 玩法

- 選角色（6 種）、選關卡環境（6 種）、選視角（第一人稱 / 第三人稱 / 俯視，遊戲中可隨時切換）。
- **三種視角資訊量是公平的**，都看不到牆壁後面：
  - 第一人稱：站在角色眼睛的高度。
  - 第三人稱：像另一個人跟在主角後方的**平視**視角，鏡頭比牆矮；後方有牆時鏡頭會自動拉近，不會穿牆。
  - 俯視：只露出玩家腳邊一圈（半徑約一格半）的圓形視野，其他區域被雲霧遮住；可拉近拉遠。
  - 例外：🦉 貓頭鷹道具可以短暫看到整個迷宮。
- 走到金色傳送門就過關，**越快過關分數越高**。
- **飽足感**會隨時間減少（預設 3 分鐘從 100% 到 0%，後台可調），**歸零就闖關失敗**。
  - 飽足感 ≤ 50%：移動速度 ×0.8（降低五分之一）
  - 飽足感 ≤ 25%：移動速度 ×0.75（降低四分之一）
  - 加速道具是乘在「降速後」的數值上。
- 迷宮每隔一段時間會**變形**：變形時人物不能移動並顯示「迷宮變換中」警告；新迷宮是**以人物所在位置為中心重新生成**，玩家永遠不會被牆壁困住（完美迷宮演算法保證所有格子相通）。
- 變形時**出口也會搬家**：新位置在迷宮外圈的四個角或四條邊線上的任一格（單機保證離玩家有一段距離），記得看小地圖。
- 每次變形會隨機重新出現道具**和食物**。

## 💎 尋寶模式（單機打電腦 / 多人連線）

- 小地圖會標出寶藏 💎 的位置，**撿到寶藏後帶到出口 🚩 才算獲勝**。出口在外圈、寶藏保證離出口至少 1/3 張地圖遠，搶到手還得跑一段路，隨時可能被劫。
- **單機**：標題畫面選「💎 尋寶對戰」，會有電腦對手來搶（13×13 以下 1 個、15×15 以上 2 個）。電腦會自己找寶藏、搶奪、帶去出口。
- **多人**：多人連線選「💎 尋寶」；15×15 以上的大地圖若人數不足 3 人，由電腦補位。
- **攻擊與搶奪**：有人拿到寶藏後，沒拿寶藏的人會出現攻擊鍵（電腦按 `X`），每個職業武器不同：
  小勇🗡️小木劍、小花🍳平底鍋、阿丹🥊拳擊手套、莉亞✨魔法棒、鐵蛋🔧大扳手、喵喵🐾貓爪。
  - 打中任何人 → 對方**暈眩 3 秒**（後台可調）。
  - 打中「寶藏持有者」→ 搶走寶藏（同時對方暈眩）。
  - 拿著寶藏的人**不能攻擊**（雙手抱著寶藏）。
- 寶藏被拿走後，持有者位置**每 3 秒**（後台可調）在小地圖上更新一次，大家都追得到。
- 此模式不會肚子餓；迷宮照樣定時變形、出口照樣搬家。

## 👥 多人連線（2～3 人）

- 標題畫面按「👥 多人連線」。房主選模式並建立房間（得到 4 位數房號），朋友輸入房號加入，房主按開始。
- **多人模式視角可自由切換**（因為三種視角都設計成看不到牆後，資訊公平）。
- 🏁 **比賽搶終點**：三人從三個角落出發，終點在迷宮正中間（距離公平），最快到的贏。有飽足感機制，餓昏＝出局。
- 👹 **鬼抓人**：隨機一人當鬼（腳下紅圈、跑速為一般玩家 1.15 倍）。**鬼要用「攻擊」打中別人才算抓到，觸碰沒有用**。2 分半後還是鬼的人輸。此模式沒有終點。
  - 🔄 **換鬼流程**：被抓到的人變成鬼，會**定住 3 秒**（戴上面具），同時全場大字公告並播放語音「換 ○○○ 當鬼，快跑啊！」——**男生角色抓到人放男聲、女生角色抓到人放女聲**（裝置沒有男女中文語音時用音調高低模擬），大家趁機逃跑。
  - ⚡ **鬼的攻擊冷卻只要 0.75 秒**（一般玩家 1.5 秒），追到就連打。
  - 👃 **鬼的敏銳鼻子**：有人在附近（預設 3 格，遊戲設定可調 1～8 格）時，鬼會聞到味道——地上沿著迷宮通道浮現 👣 **腳印路標**指引方向（越遠越淡），畫面上方顯示方向箭頭與距離幾格，第一次聞到還有吸鼻子音效。目標跑出範圍就消失；**隱身中的人氣味被遮住，聞不到**（小花的隱身仍然有效）。
  **單機也能玩**：標題畫面「選擇玩法」選「👹 鬼抓人」，跟兩個電腦對手玩——電腦當鬼會追最近的人，不是鬼時會往離鬼最遠的角落逃。
  - ⚔️ **互相攻擊**：所有人隨時可用攻擊鍵（電腦按 `X`）互打，武器同尋寶模式。
  - 🍗 **飽足感照樣會減少**（速度懲罰跟經典模式一樣：≤50% ×0.8、≤25% ×0.75），但**餓到 0% 不會失敗，只是一直跑很慢**，撿食物就能回復。
  - ❤️ **體力**：被打中扣 1 格，歸零＝暈眩（暈完體力恢復）。一般人 1 格且不自動回復；**鬼每 15 秒自動回 1 格**。
  - 👺 **鬼面具與鬼能力**：當上鬼會隨機獲得一種職業能力並戴上對應面具（大家都看得到）：
    👺疾風（速度再 ×1.12）、🎭隱身、😈體力+1、🎃道具時間×1.5、💀鐵鍬工具箱（變鬼當下立刻拿到一把）、👁️雷達。
    抽到跟自己職業相同的能力會**疊加**（例：阿丹當鬼抽到體力＝3 格；小勇疊疾風更快；喵喵疊雷達變 2.5 秒一次；小花疊隱身變 10 秒；工程師疊鐵鍬上限變 2 把）。
  - 🔁 **鬼抓人的職業能力**（取代原本用不到的能力）：阿丹＝體力 2 格、小花＝隱身 5 秒（技能鍵／`C`，冷卻 30 秒；隱身可移動、位置照常同步、仍會被打中）、喵喵＝每 5 秒在小地圖看到所有人位置。
- 兩種模式中迷宮照樣定時變形（所有人的迷宮完全同步），道具、食物大家搶（先撿先贏）。
- 連線走 MQTT over WebSocket，預設用公用伺服器 `wss://broker.emqx.io:8084/mqtt`。若學校網路擋住或想要更穩，可在後台換成其他公用 broker（如 `wss://broker.hivemq.com:8884/mqtt`）或自己架的 aedes/mosquitto。只在網路上傳玩家名字和位置，不傳其他資料。

## 操作

- **平板 / 手機**：左半邊拖曳＝虛擬搖桿移動；右半邊拖曳＝轉視角；點小地圖放大成全螢幕、小地圖左上角 ⤢ 鈕切換 1.2 倍大小；俯視時雙指開合（或＋－按鈕）拉近拉遠。
- **電腦**（按鍵用實體位置偵測，**開著注音/倉頡等中文輸入法也能玩**）：
  - `WASD` / 方向鍵：移動
  - 滑鼠按住畫面右半邊拖曳，或 `Q` / `E`：轉視角
  - `空白鍵`：用鐵鍬敲牆
  - `F`：用風箏飛牆
  - `X`：攻擊（尋寶／鬼抓人）
  - `C`：隱身技能（鬼抓人）
  - `G`：集合口哨（鬼抓人／尋寶）
  - `M`：開／關大地圖
  - `V`：切換視角
  - 俯視時滾輪或 `+` / `-`：拉近拉遠

## 遊戲設定（標題畫面 ⚙️，原「後台設定」）

- 迷宮變形間隔（0.5 ～ 10 分鐘，預設 3 分鐘）
- 每次出現的道具數量（3 ～ 12，預設 6）
- 每次出現的食物數量（2 ～ 10，預設 4）
- 飽足感可以撐幾分鐘（1 ～ 10，預設 3，歸零＝闖關失敗）
- 尋寶模式：被攻擊暈眩幾秒（1 ～ 10，預設 3）
- 尋寶模式：寶藏持有者位置每幾秒更新（1 ～ 10，預設 3）
- 鬼抓人：鬼的嗅覺範圍幾格（1 ～ 8，預設 3）
- 開放的視角（勾選第一人稱／第三人稱／俯視，單機與多人都適用）
- 多人連線伺服器網址（MQTT over WebSocket）
- 迷宮大小（11 / 13 / 15 / 特大 19 / 超大 25）
- 預設音樂開關
- 雲端分數牆 API 網址（見下方）

設定存在瀏覽器 localStorage，儲存後下一場遊戲生效。

## 分數

`分數 = max(100, 6000 − 過關秒數 × 15) + ⭐獎勵`，吃到 ⏱️ 時間寶石等於秒數 −15。

## 🏆 雲端分數牆（讓所有玩家互相看到紀錄）

預設分數只存在各自裝置的 localStorage。想共用一面分數牆有兩種免費做法：

### 方法一（推薦）：部署到 Cloudflare Pages，內建分數 API 直接生效

這個 repo 已附好 `functions/api/scores.js`（Cloudflare Pages Function），**不需要另外寫任何 API**：

1. 到 [Cloudflare Pages](https://pages.cloudflare.com) → Create a project → 連接這個 GitHub repo。
   Build 設定全部留空（純靜態網站），Deploy。
2. Cloudflare dashboard → Workers & Pages → KV → Create namespace（名字隨意，例如 `maze-scores`）。
3. 回到 Pages 專案 → Settings → Bindings → Add → KV namespace，
   **Variable name 填 `SCORES`**，選剛剛建立的 namespace，Save 後重新部署一次。
4. 完成！遊戲會自動偵測同網域的 `/api/scores`，分數牆立刻變成所有玩家共享，後台的 API 網址欄位保持空白即可。

（沒綁 KV 也能正常部署，只是分數牆維持各裝置本機模式。多人連線與 Cloudflare 無關，走的是 MQTT 伺服器。）

### 方法二：放在 GitHub Pages 等其他靜態空間，用 Google Apps Script

1. 到 [script.google.com](https://script.google.com) 建立新專案，貼上：

```javascript
const SHEET_ID = '你的Google試算表ID'; // 建一張空白試算表，把網址中的 ID 貼過來

function doGet() {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const rows = sheet.getDataRange().getValues();
  const records = rows.map(r => ({
    name: String(r[0]), char: String(r[1]), level: String(r[2]),
    timeSec: Number(r[3]), score: Number(r[4]), date: String(r[5]),
  }));
  return ContentService.createTextOutput(JSON.stringify(records))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const r = JSON.parse(e.postData.contents);
  sheet.appendRow([
    String(r.name).slice(0, 20), String(r.char).slice(0, 4), String(r.level).slice(0, 20),
    Number(r.timeSec) || 0, Number(r.score) || 0, String(r.date).slice(0, 10),
  ]);
  return ContentService.createTextOutput('ok');
}
```

2. 「部署 → 新增部署 → 網頁應用程式」，執行身分選**我**，存取權選**所有人**。
3. 把部署後的網址（`https://script.google.com/macros/s/.../exec`）貼到遊戲的「⚙️ 後台設定 → 雲端分數牆 API 網址」。

之後每次過關會自動 POST 上傳紀錄，分數牆會合併顯示雲端＋本機紀錄。

## 技術說明

- Three.js（`lib/three.min.js`，本地載入不依賴 CDN）。
- 牆壁用 InstancedMesh 一次繪製；每個關卡有自己的程序化 Canvas 材質（城堡石磚、草原樹籬、岩石、森林木板、草地、火山岩＋發光岩漿裂縫），不依賴外部圖片，行動裝置效能友善。
- 音樂與音效全部用 WebAudio 即時合成，六個關卡六種曲風：城堡＝鐘樓圓舞曲、草原＝大調快板、山洞＝回音慢板＋水滴聲、森林＝木笛五聲音階＋鳥鳴、迷霧＝小調幽靈慢板、火山＝小調冒險快板。要換自己的音樂改 `AudioEng.SONGS` / `startMusic` 即可。
- 迷宮：遞迴回溯完美迷宮 + 8% 打通率做環路；變形時從玩家所在格子重新生長。
